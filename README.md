# Auto-Form Project

Tool tự động điền Google Form từ dữ liệu mẫu có sẵn (CSV/JSON/YAML).

## Quick Start

> Xem `.agents/skills/auto-form-dev/SKILL.md` để bắt đầu với Antigravity agent.

## Project Structure

```
.agents/              # Antigravity customizations
src/                  # Source code
tests/                # Tests
data/                 # Dữ liệu mẫu và form schemas
docs/                 # Documentation
```

## Development

Sử dụng skill `auto-form-dev` trong Antigravity chat để:

- Lên kế hoạch (`Phase 1 – PLAN`)
- Thiết kế kiến trúc (`Phase 2 – DESIGN`)
- Lập trình (`Phase 3 – CODE`)
- Triển khai (`Phase 4 – DEPLOY`)
- Kiểm thử & Review (`Phase 5 – TEST & REVIEW`)
